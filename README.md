Aziza Bibi Trust — simple website
A lightweight, responsive one-page website built with plain HTML and CSS. No frameworks, build tools, or dependencies are required.
Preview locally
Open index.html in any browser.
Publish with GitHub Pages
Create a new GitHub repository (for example, aziza-bibi-trust).
Upload index.html and README.md to the repository's root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root), then save.
GitHub will provide the published website link after deployment.
Before publishing
Review the wording and add verified contact or donation details only if you want them public. The current page intentionally does not display personal account information.
